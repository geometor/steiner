Appendix Problem 3: Tangents Through a Point to an Un-Drawn Conic
=================================================================

.. rubric:: Jakob Steiner — *Die geometrischen Constructionen* (Berlin, 1833 / Leipzig, 1895)

« *To find the straight lines passing through a given point and touching a conic section given only by (a) five tangents or (b) five points.* »

**Case a (Five tangents :math:`A, A_1, \mathfrak{A}, \mathfrak{B}, \mathfrak{C}` and point :math:`B`)**: Mark intersections :math:`a, b, c` on :math:`A` and :math:`a_1, b_1, c_1` on :math:`A_1`; project :math:`a_1, b_1, c_1` from :math:`B` back onto :math:`A` at :math:`\alpha, \beta, \gamma`. The double points :math:`\mathfrak{r}, \mathfrak{s}` via fixed circle :math:`\Omega` produce the required tangents :math:`B\mathfrak{r}, B\mathfrak{s}` (or reveal that :math:`B` lies interior to the conic if :math:`\mathfrak{pq}` misses :math:`\Omega`). **Case b** reduces dually to Case a.
